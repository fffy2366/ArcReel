# 弹球打龙道具球子弹表

用途：当项目游戏类型为“反弹球玩法”，且主玩法选择“道具球组合”时使用。

核心定义：
- 球是玩家发射的子弹，用来打龙、打龙身关节、打 Boss 弱点、阻止龙手压线。
- Boss/龙首在屏幕正上方并显示血条，两只龙手或龙身关节从上方向下压迫。
- 玩家在屏幕下方发射球形子弹，通过角度、反弹、穿透、爆炸、范围伤害、控制和召唤效果击打龙身。
- UI 必须能看出游戏画面：发射角度线、Boss 血条、龙手推进警戒线、剩余球数、道具球栏、技能词条、伤害数字。
- 一场广告或一章正文只选择 2-4 种球组合，不要把整个球库全塞进去。

| 球名 | 写作时的作用 |
| --- | --- |
| 迷你子弹 | 基础子弹，持续时间内无 CD 连续发射，额外球若干秒后消失；可概率打出一团子弹并增伤。 |
| 穿透 | 穿透龙身并造成碰撞伤害；可变成激光留影二次伤害，或巨大化穿透、全屏乱斩。 |
| 分裂 | 碰撞龙身后分裂出子弹继续造成伤害；进阶后分裂子弹还能继续分裂。 |
| 炸弹 | 击中即爆炸且不反弹；可变为弹一下炸一下，扩大范围、提升伤害和爆炸外观。 |
| 激光 | 打出横排或竖排持续伤害；进阶为全屏光栅或超大激光扫龙身。 |
| 召唤 | 碰撞造成伤害并召唤士兵/召唤物协助攻击，可升级为群体伤害。 |
| 越弹越大 | 每次碰撞后体积变大、伤害提升，适合长反弹路线和密集龙身关节。 |
| 闪电球 | 每次碰撞触发范围闪电伤害；可升级为感电蔓延、雷神之锤式群体攻击。 |
| 燃烧 | 碰撞附加燃烧 buff，持续掉血；带燃烧的龙身关节死亡时可触发火焰爆炸。 |
| 毒球 | 碰撞附加毒 buff，叠到一定层数后可引爆所有中毒目标并按最高层数结算。 |
| 诅咒 | 碰撞附加诅咒，让目标受到额外伤害；进阶可全屏施加高额增伤。 |
| 旋转刀 | 碰撞若干次后在定点形成范围斩击；结束时爆炸并按方向发射贯穿飞刀。 |
| 钻头 | 支线攻击，打掉怪物后继续前进且不反弹；可触发地震范围百分比伤害。 |
| 怒气 | 怒气满后释放高攻击强机制球，适合 Boss 残血或龙手压线时爆发。 |
| 百分比 | 每次攻击按怪物血量上限扣血，适合高血量 Boss 或厚血龙身。 |
| 标记 | 碰撞处被标记后受到额外轰炸伤害，可表现为直升机/火力支援；进阶可全屏殉爆。 |
| 冰冻球 | 碰撞概率冰冻或减速龙身；可触发冰爆、暴风雪全屏减速和伤害。 |
| 减益增伤 | 碰撞让目标后续受到的攻击提高，是辅助输出球。 |
| 闪现球 | 从屏幕上方发球，制造天花板方向攻击；可单次碰撞叠加多种伤害。 |
| 重力球 | 球受到向上重力牵引，改变反弹路径；可形成黑洞范围伤害并放大范围内所有伤害。 |
| 双子连线 | 发射多个不同角度的球，球与球之间连线额外造成切割伤害。 |
| 虚空球 | 制造持续虚空区域，龙身在区域内虚化，其他球可穿过并追加区域伤害和 debuff。 |
| 地震球 | 碰撞触发震荡冲击，造成大范围地震式伤害。 |
| 寄生球 | 碰撞龙身后给当前关节挂刀刃，刀刃伤害相邻龙身；进阶为双侧刀刃或电锯高暴击。 |
| 光棱球 | 穿透后碰墙消失并计算折射角，形成持续激光束；围成封闭空间时对内部龙身持续高伤。 |
| 铁球 | 有 CD 的重型穿透球，造成半径范围伤害；进阶可变大或双铁球加铁链连伤。 |
| 河豚球 | 挂在龙身上，受攻击后周期性射出穿透针；进阶可针刺分裂、叠伤后爆炸。 |
| 狂斩球 | 每次碰撞龙身触发半月斩范围伤害；进阶发射剑气或触发全屏镜头斩。 |
| 大聪明球 | 碰撞后飞出种子落到宝箱或目标点，生根开花并持续造成伤害，开花后范围爆发。 |
| 雷神球 | 碰撞时向命中点和最近龙身关节释放雷电；进阶落下宙斯闪电并分裂球形闪电。 |
| 弓塔球 | 碰撞后在地图随机区域投射弓箭塔，弓塔存在一段时间并攻击范围内最近龙身。 |
| 冰神球 | 碰撞概率冰冻减速并发射贯穿冰锥；每隔一段时间触发全屏暴风雪与冰雹伤害。 |
| 跃迁球 | 碰撞后向全屏龙身关节发射节点并造成持续伤害，结束后回收沿途再伤害。 |
| 屏幕震荡波 | 球碰屏幕边缘时，边缘向对面发射冲击波伤害区域内龙身；进阶可反弹一次。 |
| 欧拉球 | 每次接触屏幕边缘触发拳头矩形推进伤害，进阶为巨大贯穿拳头多段打击。 |

组合示例：
- 控制压线：冰冻球 + 穿透 + 炸弹。先冻住推进龙手，再穿透关节，最后爆炸清盾。
- Boss 爆发：诅咒 + 百分比 + 雷神球。先叠增伤，再按血量上限扣血，最后雷电爆发打 Boss 血条。
- 密集清屏：分裂 + 越弹越大 + 屏幕震荡波。通过多次反弹扩大覆盖面，清掉龙卵和龙鳞障碍。
- 光路封锁：光棱球 + 重力球 + 双子连线。用折射激光和连线切割封住龙身路径。
